# Derby

Pons token launches on Robinhood Chain, shown as a live horse race. Distance is the ETH in a token's bonding curve; the winning post is 4.2 ETH.

A static site with no build step:

- `index.html` - the whole app
- `snapshot.json` - recorded launches, used when the live feed is unavailable
- `og.png` - link preview image

To run it locally, serve this folder with any static file server and open it in a browser.

Odds and flags are automatic readings of on-chain data. They are not predictions, accusations or financial advice.
